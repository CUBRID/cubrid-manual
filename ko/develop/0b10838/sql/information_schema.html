Information Schema

Information Schema는 현재 데이터베이스의 객체(테이블, 칼럼, 제약 조건, 루틴, 권한 등)에 대한 메타데이터를 제공하는 읽기 전용 뷰의 집합이다. Information Schema는 SQL 표준(ISO/IEC 9075-11)으로 정의되어 있어 이식성이 높고 안정적이다. 이는 CUBRID에 특화되어 있고 구현상의 고려 사항을 반영하여 설계된 시스템 카탈로그와 대비된다.

-- 사용자 'PUBLIC'이 소유한 테이블
SELECT table_name, table_type
FROM information_schema.tables
WHERE table_schema = 'PUBLIC';

-- 'game' 테이블의 칼럼
SELECT column_name, data_type, is_nullable
FROM information_schema.columns
WHERE table_name = 'game'
ORDER BY ordinal_position;

referential_constraints 뷰는 현재 데이터베이스의 모든 참조(외래 키) 제약 조건을 제공한다. 단, 현재 사용자가 참조하는 테이블을 소유하거나 그에 대해 SELECT 외의 권한을 가진 제약 조건만 표시된다.

unique_constraint_schema

VARCHAR(32)

VARCHAR(255)
