*****************************
PL/CSQL
*****************************

CUBRID supports the development of stored functions and procedures using PL/CSQL (Procedural Language extension of CUBRID SQL).
PL/CSQL is an extension of CUBRID SQL to a procedural language, supporting procedural language features such as conditional statements, loops, variables, error handling, and modularization through internal procedures/functions,
which are difficult to implement with declarative SQL alone.
Of course, SQL statements can be included and used together within a PL/CSQL program.
